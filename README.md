# Greedy empirical Bayes for density estimation

Code for the experiments in *Greedy empirical Bayes for density estimation*.
See the paper and appendix for methodological details and experimental settings.
Paper link: https://arxiv.org/abs/2611.22796

## Contents

- [notebooks/](notebooks/) — experiment notebooks and a GEB quickstart.
- [methods/GEB/](methods/GEB/) — the GEB density estimator.
- [methods/baseline/](methods/baseline/) — classical Pólya tree (PT), variational DPMM, and the R interface to HMPT.
- [experiment_utils/](experiment_utils/) — benchmark settings, coordinate transforms, experiment runner, and LaTeX table generation.
- [data/](data/) — preprocessing code in `preprocess/`, source data in `raw/`, and generated splits in `train_test/`.
- `results/` — generated CSV files, figures, and LaTeX tables.

## Installation

From the repository root, install the Python dependencies:

```bash
python -m pip install -r requirements.txt
```

Select this environment as your Jupyter kernel. For a minimal GEB example, see [06_GEB_quickstart.ipynb](notebooks/06_GEB_quickstart.ipynb).

For the R Markdown notebooks, install the following R packages and run the
chunks in order:

- HMPT: `reticulate` and [SMCMP from the HMPT authors](https://github.com/MaStatLab/HMPT_experiments).
  Configure `reticulate` to use the Python environment above.
- DPMM posterior uncertainty: `BNPmix`.

## Data preparation

The three real datasets originate from the UCI Machine Learning Repository:
[POWER](https://archive.ics.uci.edu/dataset/235),
[Dry Bean](https://archive.ics.uci.edu/dataset/602), and
[ISOLET](https://archive.ics.uci.edu/dataset/54). The simulation datasets are
generated by code.

Dry Bean and ISOLET are downloaded from UCI during data preparation. For
POWER, download the [MAF data archive](https://zenodo.org/records/1161203)
and save its `power/data.npy` as `data/raw/power.npy`.

From the repository root, prepare the data for density estimation, parameter
sensitivity, and the real-data scatterplots:

```bash
python -m data.preprocess.generate
```

The script creates 20 train/test pairs per dataset and initializes the
density result CSVs. It reuses complete sets of saved splits.

## Reproducing the experiments

| Experiment | Notebooks in run order | Output directory |
| --- | --- | --- |
| Density estimation | [Python benchmark](notebooks/01_density_estimation.ipynb), then [HMPT](notebooks/01_density_estimation_hmpt.Rmd) | `results/density_estimation/` |
| Posterior uncertainty | [DPMM in R](notebooks/02_posterior_uncertainty_dpmm.Rmd), then [GEB and comparison figure](notebooks/02_posterior_uncertainty.ipynb) | `results/posterior_uncertainty/` |
| Introduction example | [Partition comparison](notebooks/03_introduction_example.ipynb) | `results/introduction_example/` |
| Parameter sensitivity | [Candidate-grid size and concentration](notebooks/04_parameter_sensitivity.ipynb) | `results/parameter_sensitivity/` |
| Real-data scatterplots | [Training data and GEB predictive samples](notebooks/05_real_data_scatterplots.ipynb) | `results/real_data_scatterplots/` |

Run the Python density benchmark and HMPT sequentially: both update the same
CSV files. These updates also generate `simulation_table.tex` and
`real_data_table.tex` in `results/density_estimation/`.

The posterior uncertainty notebooks generate their own Laplace data. Run the
R notebook first, including its final section, then the Python notebook to
produce the posterior comparison figure. The introduction example and
quickstart also generate their own data.

Density estimation, coverage, and parameter sensitivity
save completed repetitions and skip them on rerun. If you change the model
settings, clear the affected results before rerunning so the notebook
recomputes them.
